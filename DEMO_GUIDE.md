# Five-minute faculty demonstration

1. **Dashboard (45 sec):** Show balance, income, expense, savings, health gauge, cash-flow charts, allocation, recent transactions, and the synthetic-data label.
2. **Dataset Explorer (60 sec):** Walk through the calculated raw dataset profile, monthly income/expense data, window preview and split boundaries, then the Autoencoder feature table and downloads.
3. **LSTM (70 sec):** Open Deep Learning Lab, train the LSTM, explain its 64/32 recurrent layers and chronological holdout, then show train/validation loss, test actual-vs-predicted, residuals, metrics, and naive baseline comparison.
4. **Autoencoder (60 sec):** Train it, explain the four standardized features and 3-value bottleneck, then show reconstruction-error histogram, threshold, and highest-error expense rows.
5. **Financial insights (35 sec):** Show spending/budget/portfolio agents and the Decision Coordinator. Explain which outputs are based on recorded data and which require trained models.
6. **Functionality (30 sec):** Briefly demonstrate adding/editing a transaction and the CSV report download. Reset Demo Data restores the fictional sample if needed.

Allow extra time for TensorFlow’s first import and model training. Training results are data- and run-dependent; do not quote values before training the current demo dataset.
